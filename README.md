# Splitting the G — a G-clef, not a pint

Original poster for [poidh #1552, “split the G your way”](https://poidh.xyz/base/bounty/1552) (on-chain id 566, Base).

The treble clef is a G-clef. It is named for the G line it curls around. The poster opens the clef along that line.

- Image: [proof/split-the-g.png](proof/split-the-g.png)
- Rebuild: `python3 make_art.py`

The poster composition, typography, colour, and split are original. The G-clef outline is adapted from Wikimedia Commons [File:GClef.svg](https://commons.wikimedia.org/wiki/File:GClef.svg) (public domain, author っ, 27 April 2006).
